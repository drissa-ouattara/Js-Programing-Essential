01

Arrays

Declare, index & count

Arrays keep values in order. Read the first item at index 0; use length to count items.

const fruits = ["apple", "banana", "cherry"];
const firstFruit = fruits[0];
const numberOfFruits = fruits.length;

console.log(firstFruit);       // "apple"
console.log(numberOfFruits);   // 3

Change an array

Arrays are mutable: you can replace an item or assign a value at a new index.

const fruits = ["apple", "banana", "cherry"];
fruits[2] = "strawberry";
fruits[3] = "kiwi";

console.log(fruits);

push() and pop()

Add to the end, or remove and return the last item.

const fruits = ["apple", "banana"];
fruits.push("orange", "strawberry");
const removedFruit = fruits.pop();

console.log(fruits);       // ["apple", "banana", "orange"]
console.log(removedFruit); // "strawberry"

shift() and unshift()

Remove from the beginning, or add one or more items at the beginning.

const fruits = ["banana", "orange"];
fruits.unshift("apple", "strawberry");
const firstFruit = fruits.shift();

console.log(fruits);     // ["strawberry", "banana", "orange"]
console.log(firstFruit); // "apple"

splice()

Remove, replace, or insert items in place. Arguments: start index, delete count, then any new items.

const fruits = ["apple", "banana", "cherry"];
fruits.splice(1, 1, "grape");

console.log(fruits); // ["apple", "grape", "cherry"]

concat() and slice()

concat() joins arrays. slice(start, end) copies a portion; the end index is excluded.

const fruits = ["apple", "banana", "cherry", "orange"];
const moreFruits = fruits.concat(["kiwi"]);
const selected = fruits.slice(1, 3);

console.log(moreFruits); // [..., "kiwi"]
console.log(selected);   // ["banana", "cherry"]

indexOf()

Returns the first matching index, or -1 when the item is absent.

const fruits = ["apple", "banana", "cherry", "banana"];
const index = fruits.indexOf("banana");

console.log(index); // 1

reverse() and sort()

Both sort the original array. The default sort compares values as strings; use a comparator for numbers.

const numbers = [4, 2, 8, 6, 1, 10];
numbers.sort((a, b) => a - b);
console.log(numbers); // [1, 2, 4, 6, 8, 10]

numbers.reverse(); // reverses this array in place
02

Iteration & transformation

for loop

Useful when you need the index or precise control over the loop.

const fruits = ["apple", "banana", "cherry"];
for (let index = 0; index < fruits.length; index++) {
	console.log(fruits[index]);
}

forEach()

Runs a function for each item. Use it for an action; it does not create a transformed array.

const users = [
	{ name: "Alice", email: "alice@example.com" },
	{ name: "Bob", email: "bob@example.com" }
];

users.forEach((user) => {
	console.log(`Welcome email sent to ${user.email}`);
});

map()

Transforms every item and returns a new array with the results.

const products = [
	{ name: "Laptop", price: 1000 },
	{ name: "Tablet", price: 300 }
];

const labels = products.map(
	(product) => `${product.name}: $${product.price}`
);
console.log(labels);

filter()

Returns a new array containing only items that pass the condition.

const products = [
	{ name: "Laptop", price: 1000 },
	{ name: "Tablet", price: 300 },
	{ name: "Keyboard", price: 50 }
];

const affordable = products.filter(
	(product) => product.price >= 100 && product.price <= 500
);

reduce()

Combines the array into one value. The second argument sets the initial accumulator.

const prices = [50, 30, 25, 40, 15];
const total = prices.reduce(
	(sum, price) => sum + price,
	0
);

console.log(total); // 160

find()

Returns the first item that matches, or undefined if nothing matches.

const employees = [
	{ id: 1, name: "Alice" },
	{ id: 2, name: "Bob" }
];

const employee = employees.find((person) => person.id === 2);
console.log(employee.name); // "Bob"
03

Objects

Object literal & dot notation

An object stores values under named properties. Access ordinary property names with a dot.

const person = {
	firstName: "Alice",
	age: 30,
	getFullName() {
		return this.firstName;
	}
};

console.log(person.firstName); // "Alice"

Bracket notation

Use brackets when a property name contains spaces or when its name comes from a variable.

const person = {
	"first name": "John",
	age: 30
};

console.log(person["first name"]); // "John"
const key = "age";
console.log(person[key]);          // 30

Classes & instances

A class defines how its instances are initialized and which methods they have.

class Person {
	constructor(firstName, lastName) {
		this.firstName = firstName;
		this.lastName = lastName;
	}

	getFullName() {
		return `${this.firstName} ${this.lastName}`;
	}
}

const person = new Person("John", "Doe");
console.log(person.getFullName());

Constructor function

A traditional way to create objects. Call it with new; class syntax is common in modern JavaScript.

function Car(make, model) {
	this.make = make;
	this.model = model;
}

const car = new Car("Toyota", "Camry");
console.log(car.make); // "Toyota"

Arrays of objects & nested data

Combine arrays and objects to represent collections of structured records.

const students = [
	{ name: "Alice", age: 25, hobbies: ["Reading", "Traveling"] },
	{ name: "Bob", age: 22, projects: [{ title: "Project A", completed: true }] }
];

console.log(students[0].name);                    // "Alice"
console.log(students[0].hobbies[0]);              // "Reading"
console.log(students[1].projects[0].title);       // "Project A"

students.push({ name: "Charlie", age: 28 });      // add at end
const removedStudent = students.pop();            // remove from end
const adults = students.filter((student) => student.age >= 23);
const studentNames = students.map((student) => student.name);
04

2D arrays & booking

Rows and columns

A 2D array is an array containing arrays. Use two indexes to access a cell.

const grid = [
	[1, 2, 3],
	[4, 5, 6],
	[7, 8, 9]
];

console.log(grid[1][2]); // 6

for (let row = 0; row < grid.length; row++) {
	for (let column = 0; column < grid[row].length; column++) {
		console.log(grid[row][column]);
	}
}

Movie theater seats

O means available and X means booked. Select a seat or book one at random.

const seats = [
	["X", "O", "X"],
	["O", "X", "O"],
	["X", "O", "X"]
];

function bookSeat(row, column) {
	if (seats[row][column] === "O") {
		seats[row][column] = "X";
		return true;
	}
	return false;
}
05

Strings

Length, indexing & case

Strings represent text. Their indexes start at zero, and length counts characters.

const text = "JavaScript";
console.log(text.length);       // 10
console.log(text[0]);           // "J"
console.log(text.toLowerCase());
console.log(text.toUpperCase());

Search within text

indexOf() returns a position or -1; includes() returns a boolean.

const sentence = "The quick brown fox jumps.";
console.log(sentence.indexOf("fox")); // 16
console.log(sentence.includes("fox")); // true

slice() & substring()

Both extract text between indexes; the end index is excluded. slice() also supports negative indexes.

const text = "Hello, World!";
console.log(text.substring(0, 5)); // "Hello"
console.log(text.slice(7));        // "World!"
console.log(text.slice(-6));       // "World!"

replace(), split() & trim()

Replace text, split a string into an array, or remove whitespace from both ends.

const text = "  Alice,25,New York  ";
const cleanText = text.trim();
const fields = cleanText.split(",");
const greeting = cleanText.replace("Alice", "Bob");

console.log(fields); // ["Alice", "25", "New York"]

Template literals & concatenation

Backticks allow interpolation with ${...} and multiline strings. The + operator can concatenate strings too.

const firstName = "Peter";
const greeting = `Hello, ${firstName}!`;
const alsoGreeting = "Hello, " + firstName + "!";
console.log(greeting);
06

Math & randomness

Round numbers

round() rounds to the nearest integer, ceil() upward, and floor() downward.

const number = 3.6;
console.log(Math.round(number)); // 4
console.log(Math.ceil(number));  // 4
console.log(Math.floor(number)); // 3

Powers, roots & logarithms

pow() raises a number to a power; sqrt() finds its square root; log() is the natural logarithm.

console.log(Math.pow(2, 3)); // 8
console.log(Math.sqrt(2));   // about 1.414
console.log(Math.log(2));    // about 0.693

Math.random()

Returns a decimal from 0 inclusive to 1 exclusive. This expression picks a random array index.

const quotes = ["Keep learning.", "Make it work, then make it clear."];
const randomIndex = Math.floor(Math.random() * quotes.length);
const randomQuote = quotes[randomIndex];
console.log(randomQuote);
07

Dates & time

Create a date

Month indexes are zero-based in the numeric constructor: 0 is January.

const now = new Date();
const specificDate = new Date(2023, 0, 15); // Jan 15, 2023
const fromMilliseconds = new Date(1672569600000);

Read & format a date

Get individual date parts or format according to the user's locale.

const date = new Date();
console.log(date.getFullYear());
console.log(date.getMonth()); // 0–11
console.log(date.getDate());  // 1–31
console.log(date.toLocaleDateString());
console.log(date.toLocaleTimeString());

Date arithmetic

Date setters can adjust a date; for elapsed time, compare timestamps.

const date = new Date();
date.setDate(date.getDate() + 7); // add 7 days

const start = Date.now();
const end = Date.now();
const elapsedSeconds = (end - start) / 1000;

setTimeout()

Schedules one callback after a delay measured in milliseconds.

setTimeout(() => {
	console.log("This appears after 2 seconds.");
}, 2000);

setInterval() & clearInterval()

Repeats a callback until you cancel it. Keep the returned interval ID so it can be cleared.

let count = 0;
const intervalId = setInterval(() => {
	console.log(`Count: ${count}`);
	count++;

	if (count > 5) {
		clearInterval(intervalId);
	}
}, 1000);

Random quote generator

Choose and display a quote

Generate a valid random index, read that array item, and place it in the page.

Your next quote will appear here.

const quotes = [
	"Life is what happens when you're busy making other plans.",
	"The only way to do great work is to love what you do.",
	"Don't count the days, make the days count."
];

function generateRandomQuote() {
	const randomIndex = Math.floor(Math.random() * quotes.length);
	document.getElementById("quoteDisplay").textContent = quotes[randomIndex];
}
